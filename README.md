**Cours :** Cloud Computing - Devoir Cloudinary

## Présentation du projet

Ce site est mon Portfolio. Il présente mon université, l'Université de l'Assomption au Congo (UAC), avec une galerie de 3 photos.

Le site contient :
- Une présentation de moi
- Une galerie de 3 images de l'UAC avec titre et description pour chaque image
- Mes compétences
- Mes informations de contact

## Technologies utilisées

- HTML
- CSS
- JavaScript (pour ouvrir les images en grand quand on clique dessus)
- Cloudinary pour héberger les images
- GitHub pour publier le code
- GitHub Pages pour mettre le site en ligne

## Comment Cloudinary est utilisé

Les 3 images ne sont pas dans le dossier du projet. Elles sont stockées sur Cloudinary et affichées dans le site avec leurs liens Cloudinary (res.cloudinary.com).

C'est ça qui prouve que j'ai utilisé Cloudinary comme le prof a demandé.

## Les 3 images de la galerie

1. **Le Rectorat de l'UAC**
Le bâtiment du Rectorat de l'Université de l'Assomption au Congo à Butembo. C'est le cœur de l'administration de l'université. Devise : Noverim Me, Noverim Te.

2. **Bienvenue à l'UAC**
Bienvenue à l'Université de l'Assomption au Congo. Notre formation est assurée avec un laboratoire informatique, une bibliothèque numérique, et des terrains de pratiques professionnelles.

3. **Inscriptions Spéciales 2026-2027**
L'UAC lance les inscriptions spéciales pour l'année académique 2026-2027 pour le Master Complémentaire, pour les enseignants et détenteurs d'une licence de l'ancien système PADEM.

## Fonctionnalités du site

- Site responsive : il marche bien sur téléphone et sur ordinateur
- Images cliquables : quand on clique sur une image, elle s'ouvre en grand sans quitter le site
- Chaque image a un titre et une description

## Comment exécuter le projet localement

1. Télécharger le projet ou cloner le repo
2. Ouvrir le fichier `index.html` dans un navigateur (Chrome, Firefox)
3. Il faut une connexion Internet pour voir les images Cloudinary
